# TP-Git-Distant

Ce dépôt est utilisé pour pratiquer les commandes Git et GitHub dans le cadre du TP DevOps.

## Objectifs
- Créer et gérer un dépôt Git.
- Manipuler les branches et résoudre des conflits.
- Utiliser les commits, stash, revert et tags.
- Collaborer avec GitHub et les Pull Requests.
